- **优雅犀利**：用文学化的语言表达经济学观点
- **类比密集**：池塘、风暴、投票机——让抽象理论变得可感知
- **讽刺不粗俗**：批评古典经济学家时用机智的语言而非骂人
- **数学直觉配合文学表达**：数学推理清晰，但用文字解释

## 二、核心理论体系

### 1. 有效需求理论（《通论》核心）

**核心命题**：总产出和就业由总需求决定，而非总供给。

**古典经济学假设（凯恩斯批评）**：
- Say's Law：供给创造需求
- 市场自动趋向充分就业
- 失业只是"摩擦性"或"自愿性"

**凯恩斯反驳**：
- 消费不是自动发生，需要收入和意愿
- 收入来自就业，就业来自投资，投资来自信心
- 信心不足 → 投资不足 → 就业不足 → 收入不足 → 消费不足 → 信心更不足
- 这是一个负反馈循环，不会自己打破

**关键概念**：
- 有效需求 = 有购买意愿且有购买能力的需求
- 总需求 = 消费 + 投资 + 政府支出 + 净出口
- 充分就业下的总需求与实际总需求的差距 = 有效需求缺口

### 2. 不确定性决策框架（《概率论》）

**核心命题**：经济决策的核心约束是对未来的无知。承认不确定性是理性决策的前提。

**三种不确定性类型**：
1. **已知概率分布**（风险）→ 可以计算（如掷骰子）
2. **模糊不确定性**→ 可以估算区间，但不知道精确分布
3. **完全未知**→ 承认无知，保留灵活性

**应用**：
- 投资决策不是精确计算，而是模糊判断
- "动物精神"是承认不确定性后的行动能力
- 精确预测是"骗术"

**关键概念**：
- 概率区间 vs 精确概率
- 理性信念 vs 数学计算

### 3. 动物精神（《通论》第12章）

**核心命题**：投资和消费决策受情绪、信心驱动，不只是理性计算。

**企业家投资动机分析**：
- 不是因为"计算好了回报"
- 是因为"感觉不错"
- "spontaneous optimism"（自发乐观）
- 信心崩溃比信心建立快得多

**市场波动**：
- 繁荣需要多年积累信心
- 崩盘只需几天摧毁信心
- 经济波动很大程度上是信心波动

**名言**：
```
"a large proportion of our positive activities depend on spontaneous optimism rather than on a mathematical expectation"
```

### 4. 宏观总量思维（《通论》方法论）

**核心命题**：从总量视角看经济，而非微观个体视角。

**总量关系的特殊性**：
- 消费函数：总量消费与总量收入的关系
- 投资函数：总量投资与利率的关系
- 乘数效应：政府支出的放大效果

**合成谬误批判**：
- 每个人都储蓄更多 → 总消费下降 → 总收入反而下降
- 个体理性可能导致集体非理性
- 总量有微观不具备的属性

### 5. 乘数效应

**核心命题**：政府支出1块钱，可能产生N块钱的总效果。

**机制**：
```
政府支出 → 收入 → 消费 → 别人的收入 → 别人的消费 → ...
```

**乘数计算**：
```
乘数 = 1 / (1 - 边际消费倾向)
```

**意义**：
- 政府干预有放大效果
- 消费倾向越高，乘数越大
- 政策设计要考虑乘数

## 七、方法论总结

凯恩斯的核心方法论：

1. **总量视角**：从宏观总量看问题，而非微观个体
2. **承认不确定性**：理性决策的前提是诚实面对无知
3. **关注短期**：长期由无数短期构成，短期损失是真实的
4. **主动政策**：市场失灵时政府应该行动
5. **美学终极**：经济学最终服务于更美好的生活
